# 页面布局与 UI 设计 —— 骗子酒馆网页版

## 1. 视觉基调

- **主题**：深夜地下酒馆——暗色木纹 + 暗红绒面牌桌 + 鎏金描边，血红色作为危险色。
- **配色**：

| 用途 | 色值 |
|---|---|
| 页面底色 | `#0d0805 → #1a1109` 径向渐变 |
| 牌桌绒面 | `#4a1518 → #2a0b0e` 径向渐变（暗红绒布） |
| 木桌沿 | `#3a2415` + 内阴影 |
| 鎏金强调 | `#d4af37`（标题描边、按钮、选中光环） |
| 危险红 | `#c0392b`（质疑按钮、死亡、恶魔） |
| 卡牌纸面 | `#f7f1e3`，红桃 `#b3282d`，黑桃 `#1d1d1f` |
| 恶魔牌 | `#2b0f12` 底 + `#e05252` 字 + 😈 角标 |

- **字体**：标题用衬线（Noto Serif SC / STSong / serif），正文系统无衬线。
- **恶魔模式**：房间与牌桌整体叠加暗红滤镜（body.devil-mode），目标牌框泛红光。

**各区要点**

- **对手座位卡**：头像 + 名字 + 手牌数（🂠×n）+ 受罚标记（🔫×n，n≥2 变红）+ 状态；当前行动者金色呼吸光圈 + 倒计时环；死亡变灰 + 💀；断线接管显示 🤖。
- **牌桌中央**：目标牌竖版大卡（K/Q/A）；右侧牌堆为一叠背面卡（叠影效果）+ 总数角标；下方一行"上家动态"文本。
- **手牌区**：扇形平铺，悬浮上浮 8px；选中上浮 22px + 金色描边；恶魔牌常显 😈 角标（只有自己能看到自己的恶魔牌）。
- **行动按钮**：`出牌(n)` 金色；`质疑！` 血红大按钮，不可用时置灰并给原因提示（"本局第一手不可质疑"/"你已被强制质疑"）。倒计时最后一档按钮闪烁。
- **战报面板**：右侧固定 260px，滚动，事件按类型着色（出牌=灰、质疑=橙红、轮盘=血红、恶魔=紫红、死亡=黑底红字）。

### 2.4 全屏覆盖层（Overlay，按序播放）

1. **验牌层**：牌堆上移翻开，逐张亮出"真牌(绿框)/假牌(红框)"，判定文案大字："说谎成立！" / "质疑失败！"
2. **恶魔现身层**：全屏暗红闪光 + 巨大 😈 + "恶魔现身" 血字，随后进入轮盘层。
3. **轮盘层**：暗色全屏；中央 🔫（指向太阳穴的动效）；逐发播放——每发 1.2s：扳机音"咔嗒"，空枪显示"咔嗒… 空枪"；命中则巨响 + 红屏震动 + "💀 中弹身亡"；强制单发显示"恶魔逼你扣下扳机"。多个受罚者按队列依次播放，队列进度点显示在底部。
4. **终局层**：👑 胜者头像 + "最后的幸存者"；平局显示"全桌覆灭"；[再来一局]（房主）/ [回到大厅]。
5. **局间横幅**：新一局轻量横幅"第 N 局 · 本局目标 Q"从中央淡入淡出。

## 3. 交互规则映射

| 引擎规则 | UI 表现 |
|---|---|
| 一次出 1–3 张 | 选牌计数，出牌按钮实时显示 `出牌(n)` |
| 恶魔牌只能单出 | 选中恶魔牌时其他牌禁选，按钮变 `打出恶魔牌😈` |
| 空手跳过 | 手牌 0 的座位自动置灰，行动权高亮跳过 |
| 只剩一人有牌必须质疑 | 该玩家出牌按钮禁用，文案"你必须质疑上家！" |
| 第一手不可质疑 | 质疑按钮置灰 + tooltip |
| 30s 超时 | 座位倒计时环，≤5s 变红闪烁 |
| 受罚次数递增 | 🔫×n 徽章，n≥2 红色警示 |

## 4. 音效（WebAudio 程序合成，零素材）

- `click` 扣牌 / 选牌：短噪声脉冲
- `tick` 空枪：金属咔嗒（高频短振）
- `bang` 中弹：低频轰鸣 + 快速衰减
- `devil` 恶魔现身：低沉下滑音
- 默认开启，右上角 🔊 切换静音（localStorage 记忆）。

## 5. 响应式

- 设计基准 1280×800；`<900px` 时战报面板折叠为可开合抽屉，座位卡缩小；`<600px` 对手区两行网格，手牌可横向滚动。桌面优先，移动端可玩。
